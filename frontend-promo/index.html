FEATURE 02

チャートの続きは、自分の手で描く。

ローソク足の右側の余白はただの空白ではありません。マウスをドラッグするだけで予測足を描き足せる、独自のキャンバスです。

右端をドラッグすると、チャートが「続き」を持つ

始値から終値までドラッグした距離がそのままローソク足の実体に、上下への振れがヒゲになります。1回のドラッグで複数本を連続して描ける「連続描画」にも対応し、移動平均線・ボリンジャーバンドは描いた足に追従してリアルタイムに延長されます。

  • ドラッグの始点・終点・振れ幅がそのまま OHLC になる直感操作
  • MA5 / MA25 / MA75・ボリンジャーバンドが予測足に沿って自動延長
  • 東証の値幅制限テーブルを内蔵し、ストップ高・ストップ安の外へは伸ばせない
  • 直線ツールで抵抗線・支持線も自由に引ける

System Overview

システム概要

Yahoo Finance から株価データを自動取得し、DuckDB にキャッシュ。高速なローカル DB で繰り返し参照の待ち時間をゼロに近づけます。

🌐
対応市場
日本株: 4桁コード（例: 7203）
米国株: ティッカー（例: AAPL, MSFT）
内部的に日本株は末尾に .T を付加して Yahoo Finance に問い合わせます。
🗄️
データ仕様
最大 10年分 の OHLCV データを DuckDB にキャッシュ。
2回目以降は DB から高速返却。データが古い場合のみ Yahoo Finance から差分取得します。
⚡
データ鮮度
日足: 直近平日まで
週足: 当週月曜日まで
月足: 当月 1 日まで
鮮度チェックが自動で走り、古ければ差分取得します。
Quick Start

クイックスタート

最短 3 ステップでチャートを表示します。初回起動時は Yahoo Finance からデータを自動取得するため、数秒かかる場合があります。

1

バックエンドを起動する

ターミナルで以下コマンドを実行します。--reload オプションでファイル変更を自動検知します。

cd stock-chart/backend
uvicorn main:app --reload --port 8000

起動成功すると http://localhost:8000 で API が待ち受けます。初回起動時に DuckDB ファイル (stock.duckdb) が自動生成され、証券マスターデータのバックグラウンド取得も開始します。

2

フロントエンドをブラウザで開く

ファイルマネージャーまたは以下コマンドで frontend/index.html をブラウザで開きます。

open stock-chart/frontend/index.html

バックエンドが起動済みであれば、ページを開いた時点で銘柄マスターの検索サジェストが有効になります。

3

銘柄コードを入力してチャートを表示する

上部入力欄に証券コードを入力します。入力すると候補がドロップダウンで表示されます。

7203 → トヨタ自動車 9984 → ソフトバンクグループ AAPL → Apple Inc. MSFT → Microsoft

候補を選択するか Enter キーを押すとデータを取得してチャートが描画されます。初回は Yahoo Finance からダウンロードするため数秒かかります。

4

（任意）Python 依存パッケージをインストールする

初回セットアップ時のみ実行します。

cd stock-chart/backend
pip install -r requirements.txt
fastapi 0.138.1 uvicorn pandas 2.2.1 duckdb 1.5.4 httpx 0.28.1
Features

機能詳細

チャートの読み取りから将来予測の描画まで、分析に必要な機能を網羅しています。

🔍
銘柄検索・オートコンプリート
入力欄に証券コードや銘柄名の一部を入力すると、180ms のデバウンスをかけて API を呼び出しドロップダウンに最大 8 件の候補を表示します。

キーボード操作: ↑ / ↓ で候補移動、Enter で確定、Esc で閉じる。

入力可能文字は英数字・ドット（.）・ハイフン（-）・キャレット（^）のみ。
7203 トヨタ自動車 JP
7201 日産自動車 JP
7202 いすゞ自動車 JP
📅
足種・表示本数の切り替え
足種: 日足 / 週足 / 月足を切り替えると即座にデータを再取得してチャートを更新します。

表示本数: 50 / 100 / 150 / 200 / 250 / 300 本から選択。デフォルトは 150 本。本数変更時は現在の表示右端を維持したまま左側の範囲を広げます。

● 足種

  • 日足 (1d): 1 営業日 = 1 本
  • 週足 (1wk): 1 週 = 1 本
  • 月足 (1mo): 1 ヶ月 = 1 本

● 本数

  • 50 本: 約 2.5 ヶ月（日足）
  • 150 本: 約 7.5 ヶ月（日足）
  • 300 本: 約 15 ヶ月（日足）
🖱️
チャートのマウス操作
ドラッグ（パン）: チャートエリアをドラッグすると左右にスクロールします。移動中は Y 軸スケールがリセットされ、表示範囲に応じた高値・安値フィット計算が行われます。

ホイール（Y軸ズーム）: 上スクロールで価格レンジを上方向に拡大、下スクロールで下方向に縮小します（比率 8% / ステップ）。

ホバー（情報表示）: カーソル位置の日付・OHLC・出来高・MA5/25/75・ボリンジャーバンド・MACD をツールバー下のインフォバーにリアルタイム表示。
🔄
データ更新（更新ボタン）
右上の「更新」ボタンを押すと現在表示中の銘柄・足種の最新データを取得します。

バックエンドは DuckDB 内の最終日付を確認し、データが「鮮度切れ」の場合のみ Yahoo Finance API を呼び出す 差分取得 を行います。既に最新の場合は API 通信なしで即座に返却されます。

ローディング中はプログレスバーとスピナーが表示され、「更新」ボタンは無効化されます。
✍️
予測ローソク足の手描き
チャート右端の余白エリア（最新足の直後のスロット）でカーソルが クロスヘア に変わります。そこでドラッグすると予測ローソク足を手描きできます。

• ドラッグ開始位置が始値、終了位置が終値になります。
• 右隣のスロットまでドラッグすると前の足が自動確定し、次の足の描画に移行します（チェーン描画）。
• 予測足の MA / BB も自動延長してリアルタイム表示されます。
• 予測足にホバーすると「予測 +1」「予測 +2」... と表示されます。
✏️
直線描画モード
ツールバーの ✏ ボタンを押すと直線描画モードが ON になります（ボタンが青くなります）。

チャートエリアでドラッグすると任意の傾きの直線を引けます。ドラッグ中はプレビュー（点線）、マウスボタンを離すと確定（実線）されます。

再度 ✏ ボタンを押すと OFF に戻り、通常のドラッグパン操作に切り替わります。直線は銘柄切替や足種変更でリセットされます。
↕️
Y軸表示モード切り替え
ツールバーの ↕ ボタンで 2 つの表示モードを切り替えます。

● OFF（デフォルト）

  • 下限 = 高値 ÷ 3
  • 上限 = 高値 × 1.01
  • 縦幅に余裕あり
  • 長期トレンドが見やすい

● ON（フィット表示）

  • 下限 = 表示範囲の安値
  • 上限 = 表示範囲の高値
  • 上下 5% パディング
  • 短期の値動きが見やすい
🎨
背景ゾーン・年境界線
チャート背景には 2 種類の色分けゾーンが自動描画されます。

青ゾーン: 直近 25 日（MA25 計算期間）
橙ゾーン: 直近 25〜75 日（MA75 計算期間）

年が変わるタイミングには縦の境界線と西暦ラベルが自動挿入されます。
Technical Indicators

テクニカル指標

チャートには 6 種類のテクニカル指標が自動計算・表示されます。計算はバックエンドの pandas で行い、DuckDB にキャッシュされます。

📈
MA5（5日移動平均）
直近 5 本の終値の単純移動平均。短期のトレンド転換を素早く捉えます。
計算式: SMA(close, 5)
📈
MA25（25日移動平均）
直近 25 本の終値の単純移動平均。中期トレンドの基準線。ボリンジャーバンドの中心線と共通。
計算式: SMA(close, 25)
📈
MA75（75日移動平均）
直近 75 本の終値の単純移動平均。長期トレンドの方向性を確認します。
計算式: SMA(close, 75)
🎯
ボリンジャーバンド（BB ±2σ）
MA25 を中心に ±2 標準偏差の上下バンド（青点線）とその間の塗り潰し帯を表示。
計算式: MA25 ± 2 × rolling_std(close, 25, ddof=1)
📊
MACD（12, 26, 9）
EMA12 − EMA26 = MACDライン（青）
MACDライン の EMA9 = シグナル（橙）
MACD − Signal = ヒストグラム（棒）
下部サブプロットに表示。ゼロライン交叉でトレンド転換を確認します。
📉
出来高（Volume）
中部サブプロットにバーチャートで表示。陽線の日は緑、陰線の日は赤で色分け。
表示形式: 1億以上 → X.X億, 1万以上 → XX万

Troubleshooting

トラブルシューティング

よくあるエラーと解決策をまとめています。

チャートが表示されず「エラー」と表示される

原因 1: バックエンドが起動していない
ターミナルで uvicorn main:app --reload --port 8000 を実行し、サーバーが起動していることを確認してください。

原因 2: ポート 8000 が別プロセスに使用されている
lsof -i :8000 で確認し、別ポートを指定する場合は app.js 内の API_BASE 定数も変更してください。

原因 3: ティッカーシンボルが存在しない
日本株は 4 桁の証券コード（例: 7203）、米国株は正式なティッカー（例: AAPL）を入力してください。

銘柄を入力してもドロップダウンが表示されない

バックエンド起動直後は証券マスターデータのバックグラウンド取得が走るため、数秒〜数十秒かかる場合があります。しばらく待ってから再度入力してください。

または、バックエンドが起動していない状態では API 呼び出しが無視されます。バックエンドを起動してからブラウザのページをリロードしてください。

データ取得中（ローディング）が終わらない

初回データ取得時は Yahoo Finance から最大 10 年分をダウンロードするため、銘柄によっては 10〜30 秒かかる場合があります。

ネットワーク環境が悪い場合や Yahoo Finance 側のレート制限に引っかかった場合も遅延することがあります。ブラウザのコンソール（F12）を開いてエラーを確認してください。

Yahoo Finance からデータが取得できない（404 エラー）

日本株: 証券コード 4 桁を入力してください（7203）。末尾の .T は自動付加されます。

米国株: 正確なティッカーシンボルを入力してください（AAPL、MSFT など）。

ETF・指数（例: ^N225）はティッカーとして直接入力可能です。

予測ローソク足が描けない（クロスヘアカーソルにならない）

予測ローソク足を描けるのは「現在表示されている最新足の直後のスロット」のみです。

チャートを右端まで（最新足が表示されるように）スクロールしてから、最新足の右側の空白エリアにカーソルを移動してください。カーソルがクロスヘアに変わったらドラッグ可能です。

直線描画モード（✏ ON）が有効な場合は予測描画が無効になります。✏ ボタンを再度押してOFFにしてください。

Y軸がホイール操作後に元に戻らない

Y 軸スケール（yScale）はパン（ドラッグ）操作を行うと自動でリセットされ、表示範囲に合った自動計算値に戻ります。

またはチャートを一度別の本数ボタンで切り替えてから戻しても Y 軸がリセットされます。

DuckDB ファイルが壊れたと思われる場合

バックエンドを停止し、stock-chart/backend/stock.duckdb および stock.duckdb.wal を削除してから再起動してください。データは Yahoo Finance から再取得されます。

rm stock-chart/backend/stock.duckdb
rm stock-chart/backend/stock.duckdb.wal
直線が意図しない位置に引かれる

直線の位置は X 軸がカテゴリインデックス、Y 軸が株価の浮動小数点値として記録されます。非常に短い（X 差が 0.2 未満かつ Y 差が 1 未満）ドラッグは誤操作とみなして記録されません。

意図しない直線はページをリロードすると消去されます（直線はメモリ上にのみ保持されます）。
